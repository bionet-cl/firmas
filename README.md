# Firmas de correo Bionet

Generador oficial de firmas de correo (diseño definido por Marketing).

**Generador:** https://bionet-cl.github.io/firmas/

## Crear una firma
1. Abre el generador y completa tus datos.
2. Pulsa **Copiar firma** y pégala en el editor de firma de Gmail, Outlook o Titan (las instrucciones están en la misma página).

## Guardar una copia
1. En el generador pulsa **Descargar .html** (el archivo lleva tus datos dentro).
2. En este repositorio entra a la carpeta `firmas/` → **Add file → Upload files** y sube el archivo con un nombre corto, por ejemplo `pcarrillo.html`.
3. Desde ese momento tu firma se abre lista para editar en:
   `https://bionet-cl.github.io/firmas/?f=pcarrillo`

También puedes abrir cualquier `.html` descargado con el botón **Abrir una firma descargada** del generador.

## Versiones anteriores
Cada cambio queda en el historial de GitHub (**History** en cualquier archivo), así que siempre se puede recuperar una versión anterior.

## Logo
El logo que usan todas las firmas está en `logo.png`:
`https://bionet-cl.github.io/firmas/logo.png`

⚠️ No cambies el nombre ni borres `logo.png`: todas las firmas instaladas dependen de esa URL.
